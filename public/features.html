All Features

Discover every capability MyShop brings to your online store — from the customer storefront to the admin backend.

🛒 Shopping

Seamless Shopping Experience

MyShop provides customers with an intuitive, fast, and beautiful shopping journey from browsing to checkout.

Searchable catalog with multi-filter support (category, type, price, stock, featured, on-sale)
Product detail pages with image gallery, lightbox, quantity selector, and related products
Smart cart with real-time sync, quantity controls, and persistent storage
URL-synced filters that are shareable and persistent across page refreshes
Category chips with active scroll-into-view behavior
💳 Payments

Secure Payment Processing

Integrated Paystack payments with automatic verification, webhook handling, and seamless checkout experience.

One-click Paystack payment initialization with redirect flow
Automatic payment verification on return with order status updates
Webhook support for reliable payment confirmation
Prices in kobo for precision, with naira display formatting
📦 Orders

Complete Order Lifecycle

Track every order from placement to delivery with a visual timeline and staff-side processing tools.

Four-stage order lifecycle: Noted → Processing → In Transit → Completed
Visual order timeline with stage badges and progress indicators
Staff-side order processing with one-step stage advancement
Search, stage filters, age filters, and sorting on order lists
💬 Messaging

Real-Time In-App Messaging

Built-in conversation system for customer support, product inquiries, and order-related communication.

Conversation threads with product, order, or general context
Live updates via Firebase Firestore real-time connection
Read markers, unread counts, and conversation search
Two-pane desktop layout / stacked mobile experience
📊 Analytics

Powerful Business Analytics

Get insights into your store's performance with comprehensive dashboards and configurable date ranges.

Revenue trends, order counts, and average order value charts
Category breakdowns and inventory distribution visualizations
Top-performing products and low-stock item alerts
Configurable date range selection for time-based analysis
🛡️ Admin

Admin & Staff Management

Full control over your store operations with audit logging, employee access management, and business configuration.

Admin dashboard with revenue, users, and product summaries
Employee access with template roles: cashier, sales rep, support, ops manager
Audit log viewer with actor, action, resource, and metadata tracking
Business config for branding, contact info, social links, and feature toggles
🔥 And More

Additional Capabilities

🔔
Notifications
Push and in-app notifications for orders, payments, and updates. Supports FCM tokens, unread counts, and browser opt-in.
📍
Address Management
Full shipping address CRUD with street, city, state, zip, country, phone, WhatsApp, and default address support.
🔒
JWT Authentication
Secure token-based sessions with automatic expiry handling, route protection, and middleware-based verification.
📧
Email Integration
Brevo API integration for transactional emails on payment confirmation, order updates, and notifications.
🚦
Rate Limiting
Built-in API rate limiting to prevent abuse with 15-minute windows and per-IP tracking, exempting critical routes.
🏷️
Product Features
Rich product data: images, tags, specs, features, sale pricing, discounts, categories, and type-specific metadata.
