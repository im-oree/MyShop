❓ FAQ

Frequently Asked Questions

What is MyShop? +
MyShop is a full-featured, role-aware e-commerce platform built with React, TypeScript, and Node.js. It supports customer shopping, payment processing through Paystack, order tracking, staff management with granular permissions, real-time messaging, analytics dashboards, and much more.
What payment methods are supported? +
MyShop currently integrates with Paystack for payment processing, which supports cards, bank transfers, USSD, and mobile money across Nigeria and other supported regions. The backend architecture also includes abstraction for future payment provider additions.
Is MyShop mobile-friendly? +
Absolutely! MyShop is built with a mobile-first design approach. Every page, from the storefront to the admin dashboard, is fully responsive and optimized for phones, tablets, and desktops. The messaging interface adapts between stacked mobile and two-pane desktop layouts.
Can I sell digital products and services? +
Yes! MyShop supports three product types: physical products with inventory tracking, services with booking details and turnaround times, and downloadable digital products with file management and license information. Each type has tailored management features.
How does staff access control work? +
MyShop features a comprehensive RBAC (Role-Based Access Control) system. Admins can assign employees predefined role templates (cashier, sales rep, support agent, operations manager) or create custom permission sets. Permissions cover products, orders, analytics, notifications, messages, and employee management with none, read, or write access levels.
Can I customize the store branding? +
Yes. MyShop includes a business configuration system where admins can set the store name, logo, description, contact details, social media links, brand colors, and feature toggles. These settings are managed through the admin panel and stored in the backend.
